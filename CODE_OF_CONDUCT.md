# Contributor Covenant Code of Conduct

## Our Pledge

We pledge to make participation in this project a harassment-free experience for
everyone, regardless of age, body size, visible or invisible disability, ethnicity,
sex characteristics, gender identity or expression, level of experience, education,
socio-economic status, nationality, personal appearance, race, caste, color,
religion, or sexual identity and orientation.

## Our Standards

Examples of positive behavior include demonstrating empathy, using welcoming and
inclusive language, providing constructive feedback, accepting responsibility,
respecting differing viewpoints, and prioritizing the safety of users and data.

Examples of unacceptable behavior include sexualized language or imagery, trolling,
insulting comments, personal attacks, public or private harassment, publishing
private information, and conduct reasonably considered inappropriate.

## Enforcement Responsibilities

Project maintainers are responsible for clarifying standards and enforcing this code
of conduct. Maintainers may remove, edit, or reject comments, commits, code, issues,
and other contributions that are not aligned with this code.

## Scope

This code applies within project spaces and when an individual officially represents
the project in public spaces.

## Enforcement

Report concerns to the maintainers privately. Reports should include relevant context
while excluding unnecessary personal or sensitive data.
